# Eastern Panopto – Auto High Quality

A free Tampermonkey userscript that automatically selects **High** video quality instead of Auto for Eastern University's Panopto videos.

## Features

- Automatically opens the video settings menu.
- Selects Quality → High.
- Works with Eastern University's Panopto video player.
- No account credentials or API keys required.
- No external data transmission.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) in Chrome.
2. Open the `.user.js` file in this repository.
3. Click **Raw** to open the userscript.
4. If Tampermonkey offers installation, review the script and click **Install**.
5. Open an Eastern University Panopto lesson and play the video.

## Compatibility

Tested with Eastern University's Panopto player in Google Chrome. Other browsers and Panopto installations have not been verified.
